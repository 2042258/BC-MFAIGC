# Supplemental research directions

These unique implementations were retained instead of deleted during publication cleanup:

- `centralized_prototypes/`: earlier centralized/diffusion/noise investigations.
- `vertical_federation/`: separate vertical-federated-learning direction.
- `early_diagnostics/`: early extraction and plotting diagnostics.

They are not used by the shared BC-MFAIGC training engine and are not claimed to be fully exercised publication entrypoints. Inspect their local-data requirements and explicit path placeholders before running them. Preserve their scientific distinctions; do not treat them as duplicated runtime engines solely because they contain older training code.
